# Project Description
The Goal of this project was to recreate the "Portal Pass Through" Effect seen in Portal (2007) and Portal 2 (2011).

# Download Instructions
1. Clone or download the Repo.
2. Open the Project in Unity (Any 2022.X.Xf1 LTS)
3. Play around in the Demo Scene!
## Controls
- WASD - Forward, Left, Back, Right
- Q - Turn Cam Left
- E - Turn Cam Right
- Space - Fire Portal
